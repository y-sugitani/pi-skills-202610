# Obsidian 基本的な書式構文

出典: <https://obsidian.md/help/syntax>

## 段落と改行

段落は**空白行**で区切る。

```md
これは段落です。

これは別の段落です。
```

### 改行（同一段落内）

`Enter`を1回押した改行はリーディングビューでは段落の続きとして扱われる。段落内で改行するには：

- 行末に**2つのスペース**を追加してから`Enter`
- `Shift+Enter`で直接改行を挿入

### 「厳密な改行」設定

**設定 → エディタ → 厳密な改行**を有効にすると、Markdown標準仕様に従う：

- スペースなし単一リターン → 2行が1行に結合される
- 末尾2スペース付き単一リターン → `<br>`で改行
- ダブルリターン → 別段落（`<p>`）

### 複数の空白の集約

リーディングビューでは隣接する複数スペース・複数空行は1つに集約される。回避するには `&nbsp;` や `<br>` のHTMLタグを使う。

## 見出し

`#` を1〜6個使う。`#`の数が見出しレベル。

```md
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

## 強調

| スタイル | 構文 | 例 |
|---|---|---|
| ボールド | `** **` または `__ __` | `**太字**` |
| イタリック | `* *` または `_ _` | `*斜体*` |
| 取り消し線 | `~~ ~~` | `~~取り消し~~` |
| ハイライト | `== ==` | `==ハイライト==` |
| ボールド+ネストイタリック | `** **` と `_ _` | `**太字 _斜体_ 太字**` |
| ボールド+イタリック | `*** ***` または `___ ___` | `***太字斜体***` |

## 内部リンク（2形式サポート）

- ウィキリンク: `[[運動の三法則]]`
- Markdown: `[運動の三法則](運動の三法則.md)`

詳細は `links-embeds.md`。

## 外部リンク

```md
[Obsidian Help](https://help.obsidian.md)
```

URLにスペースが含まれる場合は `%20` にエスケープするか、URLを `< >` で囲む。

```md
[マイノート](obsidian://open?vault=MainVault&file=My%20Note.md)
[マイノート](<obsidian://open?vault=MainVault&file=My Note.md>)
```

## 外部画像

`!` を外部リンクの前に付ける。`|幅x高さ` でサイズ指定可能。幅のみ指定するとアスペクト比維持。

```md
![Engelbart](https://example.com/img.jpg)
![Engelbart|100x145](https://example.com/img.jpg)
![Engelbart|100](https://example.com/img.jpg)
```

## 引用

```md
> 引用テキスト

\- Doug Engelbart, 1961
```

引用の最初の行に `[!info]` を追加するとコールアウトに変換される（`callouts.md` 参照）。

## リスト

### 順序なしリスト

`-`、`*`、または `+`：

```md
- 項目1
- 項目2
- 項目3
```

### 順序付きリスト

`数字.` または `数字)`：

```md
1. 項目1
2. 項目2
3. 項目3
```

`Shift+Enter` で番号を変えずに改行を挿入できる。

### タスクリスト

```md
- [x] 完了
- [ ] 未完了
```

ブラケット内に任意の文字を使うとカスタムマーカーになる：

```md
- [x] 完了
- [?] 不明
- [-] 取り消し
```

### ネストされたリスト

インデントすればネスト可能。種類を混在させてもよい。

```md
1. 親
   - 子
   - 別の子
2. 別の親
   1. 数字付きの子
```

`Tab` / `Shift+Tab` で選択リスト項目をインデント／インデント解除。

## 水平線

3つ以上の `*`、`-`、`_`：

```md
***
---
___
* * *
```

## 脚注

参照型：

```md
これは脚注[^1]です。

[^1]: 脚注本文。
[^note]: 名前付き脚注は数字として表示されるが、参照しやすい。
```

複数行脚注：各新しい行の先頭に2スペース。

```md
[^2]: 行1
  行2の続き。
```

インライン脚注（リーディングビューのみ）：

```md
インライン脚注も使える^[これはインライン脚注。]
```

## コメント

`%%` で囲む。エディタでのみ表示。

```md
これは%%インライン%%コメント。

%%
ブロックコメント。
複数行可。
%%
```

## エスケープ

`\` を前置すると特殊文字をそのまま表示：

| 文字 | エスケープ |
|---|---|
| `*` | `\*` |
| `_` | `\_` |
| `#` | `\#` |
| `` ` `` | `` \` `` |
| `\|` | `\|` |
| `~` | `\~` |

番号付きリストの自動化を防ぐにはピリオドの前にバックスラッシュ：

```md
1\. これはリスト項目になりません。
```
